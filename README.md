# WebFret

你的随身练琴本：吉他 / 尤克里里的离线 PWA。电脑点选制谱，手机读谱、循环和分块练习。界面为中文，不需要账号或后台。

## 开发与发布

需要 Node.js 24 或更新的兼容版本。依赖以 `package-lock.json` 为准。

```powershell
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

访问命令输出的 `/WebFret/` 地址。离线缓存和更新流程应使用生产构建的 `preview` 验证；开发服务器不注册生产 Service Worker。

GitHub 仓库：<https://github.com/Juliano114514/WebFret>。在仓库 Settings → Pages 中选择 **GitHub Actions**。`main` 分支推送或手动运行 Deploy 工作流后，会构建并发布 `dist`，目标地址为 <https://Juliano114514.github.io/WebFret/>。首次发布还需要完成提交、推送及仓库 Pages 设置；本地构建成功不代表已经上线。

## 使用

- **同一首歌的四种场景**：原曲主旋律、歌词和时值只选择一份共同依据，从中生成吉他伴奏、吉他指弹、尤克里里伴奏和尤克里里指弹。各谱源的调性与编配独立保存；练习副本记录来源，原谱保持原样。共同数据修改后重新生成即可采用新内容，已有副本保留手动修改。
- **三种录入格式**：新建曲谱可选择数字简谱、弦品 / 指弹谱、歌词和弦谱，或沿用基础练习谱。先添加原图，再按小节 / 乐句录入；时值、调性、拍号和指法未知时可以留空。一个曲目可以增加不同谱源，逐行打开原图校对。
- **忠实录入与补全**：数字谱支持音级、八度、临时升降、休止、附点、延音、三连音和局部拍号；弦品谱保留逐音弦 / 品，缺少时值显示 `?`；和弦谱按歌词字符位置保存切换与原图左手指号。连音、节奏型、装饰、第二声部等暂未全部结构化，原图和原始注释作为完整依据。
- **缺少时值**：优先对照原图手动填写；只能为练音明确选择等分节奏，不能将图片横向间距或歌词字符位置当成准确拍点。原谱未知字段保持未知，练习副本标记假设。
- **缺少指法**：已知旋律及调弦时，根据音高生成可弹弦品建议；伴奏使用共同旋律谱中已录入的和弦变化和固定八分分解节奏；指弹保留旋律并尝试添加手型跨度不超过四品的低声部。建议不等于演奏者认可的完整编曲，仍需试听与试弹。当前尤克里里默认普通 High-G；超音域音明确标注邻近八度替代，原谱保持原音区。
- **仓库曲库**：随网站发布的曲目。收藏到本机后，可以断网读谱和播放。编辑仓库基础谱会创建独立副本。
- **我的曲目**：IndexedDB 中的本机作品，修改后自动保存。浏览器清理网站数据会移除这些作品，请定期导出备份。
- **基础制谱**：选择小节、拍点，再填写第 1 弦至最后一弦的品位。0 是空弦，空白是不弹。支持单声部的音符、休止符、同时发声的和弦、附点、延音线、上下扫弦、换把 / 连奏滑音和最多四行逐拍歌词。
- **时值**：缺少的时值在排版和播放时补休止符；超拍操作被拒绝。需要较长音符时，先删除或缩短其他拍点。延音须承接前一拍同弦同品的音符；滑音需要后续同弦音符作为目标。
- **和弦**：点选指型会写入实际音符。自定义指型按第 1 弦起填写，`x` 表示不弹。仅标注和弦名称不会自动产生声音。
- **练习**：默认两小节，可选择 1 / 2 / 4 / 8 或自定义起止小节。25%～150% 变速不改变音高，可启用节拍器、预备拍、循环及命名练习段。
- **播放**：默认低音量 25%，不会自动播放。音量和静音在练习面板调整。一期以 SoundFont 合成示范为目标，只保证前台播放，不承诺锁屏后台播放或真人采样音色。

## 文件交换与维护曲库

主格式为 `.webfret.json`，文件带 `format: "webfret"` 和 `version: 1`。保留原有 `editable` / `guitar-pro`，扩展 `source` 曲目保存多个谱源、共同旋律来源与原图。基础谱支持逐小节拍号和三连音；练习编配记录来源、调性及建议。旧应用不能读取新增 `source` 类型，需要通过现有 PWA 更新流程加载新版。GP 曲目保留原始文件，练习设置另存。alphaTab 内部模型 JSON 只用于当前版本运行中的临时复制，不作持久化格式。

支持导入 `.gp3`、`.gp4`、`.gp5`、`.gpx`、`.gp`；GP 导入保持音符只读，可选择音轨、独奏、静音和调音量。基础谱及导入谱都可转换导出 GP7 `.gp`，另可下载导入 GP 的原始文件。GP7 转换以 alphaTab 的兼容范围为准，不承诺保留 RSE、内嵌伴奏音频或全部 Guitar Pro 原始版式。MIDI 交换不在一期范围内。

把导出的 `.webfret.json` 或 GP 文件放入 `public/scores/` 后即可生成仓库曲库。构建自动生成 `scores/catalog.json`，不要手写索引。曲库索引优先读取网络，断网回退缓存；曲目内容只有收藏到本机后才保证离线可用。此前三个原创示例已移除；当前仅保留用户提供的《一样的月光》六张附件及对应转录，三份编配保留差异，没有合并成一份伪造的“原谱”。

原图直接嵌入曲目文件，收藏、导出与备份均包含它们，不依赖附件绝对路径或外部图片链接。仅支持 JPEG / PNG / WebP；每页最多 4 MiB、每个谱源最多 16 页，单曲图片编码文本总量最多 16 MiB。曲目仍受 20 MiB 导入限制。

可选识谱工具：[Soundslice](https://www.soundslice.com/help/en/creating/pdf-import/297/tab-only-music/) 支持纯吉他 TAB，但所有识别音默认四分音符；[悦谱 Dolce](https://github.com/lodebar2026/dolce#readme) 的作者说明支持数字简谱、时值与中文歌词识别及逐音校对。没有向这些工具上传本次图片，也没有验证其识别正确率。当前仍通过手动转录入库，MusicXML / MIDI 交换尚未接入。

文件导入限制为 WebFret / 备份 20 MiB、GP 原文件 10 MiB；GP ZIP 解压总量 32 MiB、512 项，解析在 Worker 内执行并设 15 秒截止时间。安全解压需要支持 `DecompressionStream('deflate-raw')` 的现代浏览器。基础谱上限为 2000 小节、32000 拍点；GP 为 5000 小节、64 音轨。过大的完整曲库备份自动分成多份，每份最多 200 首，恢复时依次导入。恢复会原子替换相同 ID 曲目，其他作品保留。

## 实现结构

- `model`：WebFretDocument v1、基础谱、调弦、指型和输入验证。
- `sourceScore` / `SourceSong`：三种原谱录入、图片校对、共同旋律及四种练习编配；原图限定栅格 data URL 并校验编码、文件头与预算。
- `alphaTex`：将基础谱编译为 alphaTex；所有文本均作为转义字面量写入。
- `ScoreEngine`：封装 alphaTab 的渲染、播放、选轨、片段及 GP 导出。
- `storage`：Dexie 持久化，按曲目串行保存，避免连续编辑的旧写入覆盖新写入。
- `files` / `import.worker` / `gpContainer`：文件交换与 GP 解析预算校验。
- React 页面：曲库、练习、基础编辑；Hash 路由兼容 GitHub Pages 子目录。

分块模式使用临时复制的线性播放模型，移除反复和跳转标记，借助引擎 MIDI tick 时间表划定范围，保留原曲速度变化；整曲模式使用原始播放模型。歌词按照实际谱面拍点坐标绘制在谱下，缩放和换行后重新定位；长于拍点空间的歌词可通过提示查看完整内容。

PWA 缓存应用、字体、音源、Worker 和 AudioWorklet。仅资源缓存完成才显示“可离线使用”。新版本等待用户确认更新，刷新前等待本机保存队列完成。
